Projeto de Economia de Água - Colégio Estadual de Campo Machado de Assis
Descrição

Este projeto tem como objetivo conscientizar alunos, professores e a comunidade sobre a importância da preservação dos recursos hídricos. Através de educação ambiental, campanhas e gráficos de consumo, busca-se reduzir o desperdício de água e promover práticas sustentáveis na escola e na comunidade.

O site é uma apresentação visual do projeto, com seções informativas, gráficos interativos e depoimentos da comunidade escolar.

Tecnologias Utilizadas
HTML5 – Estrutura da página.
CSS3 – Estilização e layout responsivo.
JavaScript – Criação de gráficos interativos.
Chart.js – Biblioteca para gráficos.
Live Server (opcional) – Para desenvolvimento com recarregamento automático.
Estrutura do Projeto
header – Contém título e descrição do projeto.
nav – Menu de navegação para facilitar o acesso às seções da página.
section – Seções do site:
Sobre o Projeto – Explicação do objetivo.
Importância da Água – Informações sobre a necessidade de preservação.
Recursos Hídricos da Região – Descrição dos rios e aquíferos do Noroeste do Paraná.
Gráficos – Exibe dados de consumo de água antes e após a conscientização.
Imagens – Galeria de fotos do projeto.
Depoimentos – Comentários de alunos, professores e funcionários.
Contato – Informações de contato da escola.
footer – Informações de direitos autorais.
Como Executar
Clone o repositório ou baixe o arquivo index.html.
Abra o arquivo em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
Para desenvolvimento, recomenda-se usar o Live Server no VS Code para atualização automática das alterações.
Funcionalidades
Menu de navegação fixo para acesso rápido às seções.
Gráficos interativos mostrando redução de consumo de água.
Galeria de imagens com fotos do projeto.
Depoimentos que destacam o impacto do projeto na comunidade escolar.
Responsividade básica para dispositivos móveis.
Observações
As imagens da galeria são placeholders e podem ser substituídas por imagens reais do projeto.
O gráfico de consumo utiliza dados fictícios, podendo ser atualizado conforme o monitoramento real.
